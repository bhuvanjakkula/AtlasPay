# Production / regulatory checklist
Not legal advice or certification. Before real money: determine MSB/money-transmission and state licensing; banking sponsorship; BSA/AML program; CIP/KYC/KYB; OFAC/sanctions; SAR processes; Travel Rule applicability; privacy/data residency; SOC 2/ISO 27001 roadmap; PCI DSS if card data enters scope; pen test; vendor risk; BCP/DR; safeguarding/FBO design; daily reconciliation/proof; fraud/limits; regulatory reporting; corridor-by-corridor legal matrix.

Security launch gates: KMS/HSM; validated PQC implementation for intended regime; TLS/mTLS; key rotation; least privilege; maker-checker; tamper-evident audit export; SIEM; SBOM/dependency scanning; signed builds; DR test; replay tests; ledger property tests; provider outage/return simulations.
